# 全国ライブカメラ

全国各地の道路・河川・市街地・観光地・海上などのライブカメラを、都道府県・地域別にまとめて閲覧する静的Webアプリです。

静止画ライブカメラを一覧表示し、必要に応じてYouTubeライブ配信も表示できます。1府県表示だけでなく、2府県の比較表示、都道府県をまたいだカスタム表示、地図との連動、自動スクロールなどに対応しています。

- リポジトリ：<https://github.com/RI-4zuru/LiveCamera>
- 公開方式：GitHub Pages
- 構成：HTML / CSS / JavaScript / JSON
- サーバー処理・データベース：不要

> [!NOTE]
> ライブカメラ画像・映像は各提供元が公開しているものです。配信停止、URL変更、メンテナンス、埋め込み制限などにより、一時的または恒久的に表示できなくなる場合があります。

---

## 主な機能

### 都道府県・地域表示

- 都道府県選択画面から表示対象を選択
- 都道府県ごとの地域区分で絞り込み
- 第1枠・第2枠へ別々の都道府県を割り当て
- 1枠表示と2枠表示の切り替え
- 地域の並び順は各都道府県JSONの `areas` の記載順を使用
- 海に面する府県では、通常地域の最後に「海上」を配置

### ライブカメラ一覧

- 通常は静止画カメラを表示
- `YouTube` ボタンでYouTubeライブカメラを追加表示
- 画像列数を1・2・3・4・6・8列から選択
- 画像をクリックして拡大表示
- 地点名から提供元ページを別タブで表示
- 現在時刻、次回更新までの秒数を表示
- 手動の画像更新
- 画像取得に失敗したカメラを案内表示
- 表示編集でカメラを個別に非表示
- 非表示にした画像の復旧確認
- 設定はブラウザへ保存

### 地図

- カメラ位置を地図上のピンで表示
- 静止画とYouTubeでピンを区別
- ページをスクロールしても地図を常時表示
- 地図の表示・非表示切り替え
- 全域表示
- 一覧の画像へカーソルを合わせると、対応するピンを強調
- 地図のピンへカーソルを合わせると、対応する画像まで一覧を自動スクロール
- ピンをクリックした場合も対応画像へ移動

### 2枠表示

2府県または保存済みカスタム設定を左右に並べて表示できます。

自動スクロールは次の2方式に対応しています。

#### 連動

- 2枠を同じ速度でスクロール
- 画像数が少ない枠は最後の画像で停止
- 画像数が多い枠が末尾まで到達すると、両枠を同時に先頭へ戻す

#### 独立

- 左右を別々にスクロール
- 各枠が末尾へ到達すると1秒停止
- 到達した枠だけ先頭へ戻して再開
- もう一方の枠はそのままスクロールを継続

### 自動スクロール

- 停止
- 遅い
- 普通
- 速い
- 2枠表示時は「連動」「独立」を選択可能

### カスタム表示

都道府県をまたいで、任意の静止画・YouTubeライブカメラだけを選んで表示できます。

- 都道府県フィルター
- カメラ名検索
- 表示中のカメラを一括選択
- 選択解除
- 選択画像のみ表示
- カスタム設定へ名前を付けて保存
- 保存済み設定の読み込み
- 上書き保存
- 名前変更
- 削除
- 複数スロットの保存
- カメラの並べ替え
- 元の順番へ戻す
- 保存内容はブラウザの `localStorage` に保持

## ローカルでの確認方法

県別JSONを `fetch()` で読み込むため、`index.html` を直接ダブルクリックした場合は正常に動作しないことがあります。

リポジトリのルートで簡易Webサーバーを起動してください。

### Python

```bash
python -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000/
```

### Visual Studio Code

Live ServerなどのローカルWebサーバー拡張機能でも確認できます。

1. リポジトリへファイルをアップロードします。
2. GitHubの `Settings` を開きます。

Windows: Ctrl + F5
macOS: Command + Shift + R

## 都道府県一覧の管理

`data/prefectures.json` で、都道府県の表示可否を管理します。

```json
{
  "id": "shiga",
  "name": "滋賀県",
  "enabled": true
}
```

- `enabled: true`：選択可能
- `enabled: false`：データ準備中として無効表示

都道府県JSONを追加しただけでは選択できません。`prefectures.json` 側も有効化してください。

---

## 県別JSONの基本構造

```json
{
  "id": "shiga",
  "name": "滋賀県",
  "shortName": "滋賀",
  "region": "近畿",
  "center": {
    "latitude": 35.2,
    "longitude": 136.1
  },
  "zoom": 8,
  "refreshIntervalMinutes": 5,
  "areas": [
    {
      "id": "kohoku",
      "name": "湖北",
      "color": "blue"
    }
  ],
  "cameras": []
}
```

### 主要項目

| 項目 | 内容 |
|---|---|
| `id` | 都道府県を識別する英数字ID |
| `name` | 正式な都道府県名 |
| `shortName` | 画面内で使う短い名前 |
| `region` | 地方区分 |
| `center` | 地図の初期中心 |
| `zoom` | 地図の初期ズーム |
| `refreshIntervalMinutes` | 標準の画像更新間隔 |
| `areas` | 地域区分。記載順が画面の表示順 |
| `cameras` | カメラデータ |

### 地域色

現在の画面で使用している主な色IDは次のとおりです。

```text
blue
green
violet
orange
red
yellow
gold
grey
black
```

同じ府県内で隣接地域が見分けやすい色を指定してください。

## 静止画カメラの追加

```json
{
  "id": "shiga-river-001",
  "area": "kohoku",
  "city": "長浜市",
  "place": "高時川 ○○橋",
  "mediaType": "image",
  "provider": "滋賀県 河川防災カメラ",
  "pageUrl": "https://提供元のカメラ紹介ページ",
  "imageUrl": "https://直接表示できる現在画像.jpg",
  "imageRefreshSeconds": 300,
  "latitude": 35.4000,
  "longitude": 136.2000
}
```

### 必須項目

| 項目 | 内容 |
|---|---|
| `id` | ファイル内で重複しないカメラID |
| `area` | `areas` に存在する地域ID |
| `city` | 市町村名 |
| `place` | 画面に表示する地点名 |
| `mediaType` | 静止画は `image` |
| `provider` | 提供機関・配信元 |
| `pageUrl` | 提供元の案内ページ |
| `imageUrl` | 直接表示可能な画像URL |
| `latitude` | 緯度 |
| `longitude` | 経度 |

### 任意項目

| 項目 | 内容 |
|---|---|
| `imageRefreshSeconds` | カメラ固有の更新間隔 |
| `terrain` | 平地、山地、観光などの補足分類 |
| `riverName` | 河川名 |
| `imageSource` | 個別処理が必要な画像取得方式 |
| `stationId` | 提供元システムの観測所番号 |

`pageUrl` は、画像そのものではなく、原則として提供元・地点・利用条件を確認できるページを指定してください。

## YouTubeライブカメラの追加

```json
{
  "id": "kyoto-youtube-001",
  "area": "kyoto_kameoka",
  "city": "京都市東山区",
  "place": "清水坂 ライブカメラ",
  "mediaType": "youtube",
  "provider": "配信者名 / YouTube",
  "pageUrl": "https://www.youtube.com/watch?v=動画ID",
  "youtubeId": "動画ID",
  "latitude": 35.0000,
  "longitude": 135.7800
}
```

- `youtubeId` には動画URL全体ではなく動画IDを指定します。
- 通常動画ではなく、継続的に利用できるライブ配信を登録してください。
- 配信終了や動画IDの変更が多いため、定期的な確認が必要です。
- 埋め込みが禁止されている配信は、別タブで開く方式になる場合があります。

## 海上エリアの追加

海に面する府県では、通常地域の最後へ次を追加します。

```json
{
  "id": "marine",
  "name": "海上",
  "color": "black"
}
```

海上カメラ側は `area` を `marine` にします。

```json
{
  "id": "wakayama-marine-001",
  "area": "marine",
  "city": "串本町",
  "place": "潮岬から望む太平洋",
  "mediaType": "image",
  "provider": "提供元",
  "pageUrl": "https://提供元ページ",
  "imageUrl": "https://現在画像.jpg",
  "latitude": 33.4500,
  "longitude": 135.7600
}
```

`marine.json` への分離は行いません。

## 新しい都道府県を追加する手順

1. `data/cameras/` に県別JSONを作成します。
2. 都道府県の中心座標と初期ズームを設定します。
3. 地域を画面に表示したい順に `areas` へ登録します。
4. 各カメラを `cameras` へ追加します。
5. `data/prefectures.json` の該当県を `enabled: true` にします。
6. ローカルサーバーで表示を確認します。
7. 静止画、YouTube、地図ピン、地域絞り込み、カスタム画面を確認します。
8. 問題がなければGitHubへ反映します。

## データ追加時の確認項目

追加前後に次を確認してください。

### JSON

- JSON構文が正しい
- カメラIDが重複していない
- `area` が `areas` に存在する
- 画像URLが重複していない
- YouTube IDが重複していない
- 緯度経度が数値になっている
- 市町村と地域区分が一致している
- 海上エリアが通常地域の最後にある

### 静止画

- URLを直接開くと画像が表示される
- 現在時刻に近い画像へ更新されている
- メンテナンス画像や長期間停止画像ではない
- HTTPSで取得できる
- 画像の直接参照が利用条件上認められている
- RefererやCookieが必須ではない
- 画像URLに短時間で失効するトークンが含まれていない

### YouTube

- 現在もライブ配信中
- 通常動画や録画動画ではない
- 動画IDが正しい
- 配信ページが公開状態
- 地点名と実際の映像が一致している

### 画面

- 都道府県を選択できる
- 地域順が正しい
- 画像が意図した地域へ表示される
- 地図ピンの位置が大きく外れていない
- ピンから対応画像へスクロールできる
- 2枠表示で左右とも正常に動く
- カスタム画面へ読み込める

次のような画面設定はブラウザの `localStorage` に保存されます。

- 選択中の第1・第2都道府県
- 地域フィルター
- YouTube表示状態
- 非表示カメラ
- 画像列数
- 2枠表示状態
- 2枠のスクロール方式
- 自動スクロール速度

- カスタム画像の並び順

設定を完全に初期化したい場合は、ブラウザのサイトデータまたは `localStorage` を削除してください。

## 運用上の注意

### 外部画像

このアプリは、外部サイトが公開する画像を直接読み込みます。

- 提供元の利用条件を確認してください。
- 画像への直接リンクを禁止しているサイトは登録しないでください。
- URLがHTTPのみの場合、HTTPSのGitHub Pagesでは混在コンテンツとして遮断されます。
- CORS、Referer制限、Cookie、アクセス制限により表示できないことがあります。
- 無料の外部画像プロキシへ依存すると、障害や仕様変更の影響を受けるため、原則としてHTTPSの直接画像を優先してください。

### 更新停止

画像が取得できても、古い日時で止まっている場合があります。

- 画像内の撮影日時
- 提供元ページの更新時刻
- 天候や明るさの変化

を確認し、長期間停止しているものは登録しないか、表示編集で非表示にしてください。

### 緯度・経度

緯度経度はカメラ設備そのものではなく、橋・道路・施設・市町村などの概略位置を設定している場合があります。正確な設備位置が確認できた場合は、随時修正してください。

### 配信元の権利

画像・映像の著作権や利用条件は各提供元に帰属します。このリポジトリは画像・映像データ自体を保有せず、公開URLを一覧化して表示します。
